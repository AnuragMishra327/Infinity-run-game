# Infinity Run ♾️

**Live Game:** https://infinity-runn.netlify.app/

Infinity Run is a fast-paced browser endless runner where you jump over obstacles, survive longer, and beat your best score. Built with HTML, CSS, JavaScript, and HTML5 Canvas, it features dynamic obstacles, double jumping, increasing difficulty, sound controls, and a neon space-inspired design.

## 🎮 Features

- Endless runner gameplay
- Double jump mechanic
- Dynamic obstacles
- Increasing difficulty
- Personal best score
- Sound controls
- Pause and restart functionality
- Keyboard and touch controls
- Neon space-inspired design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- HTML5 Canvas
- LocalStorage
